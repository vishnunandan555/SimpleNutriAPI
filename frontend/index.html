Render REST API Endpoints

This FastAPI service is ready for deployment on Render. Test endpoints directly or copy curl commands.

GET
/api/v1/foods?category=millets&tag=iron

Filter canonical foods with nutrient composition per 100g.

GET
/api/v1/foods/search?q=spinach

Search foods by common name or regional aliases ('palak', 'cheera').

GET
/api/v1/recipes?cuisine=south_indian

List recipes with strict canonical ingredient food IDs and quantities.

GET
/api/v1/cycle/phases

Retrieve evidence-based nutritional priorities for all cycle phases.

GET
/health

Service health and database connection status for Render.
